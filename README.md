# Quantfolio

Quantfolio is a Python-based portfolio analytics library designed to model investment holdings, analyze historical market data, and evaluate portfolio performance and risk.

The project combines software engineering and quantitative finance to build a modular foundation for portfolio analysis, with potential extensions into data science, machine learning, and quantitative research.

## Current Features

- **Asset and Portfolio Modeling** — Represent investment holdings and manage portfolio positions.
- **Market Data** — Retrieve and validate historical stock-price data using Yahoo Finance.
- **Return Analytics** — Calculate simple, cumulative, total, annualized, and logarithmic returns.
- **Risk Analysis** — Measure volatility, maximum drawdown, and risk-adjusted performance using the Sharpe ratio.
- **Portfolio Analytics** — Calculate portfolio value, asset weights, returns, variance, and volatility.
- **Testing** — Use automated unit and integration tests to verify calculations and component behavior.

## Technology Stack

- Python 3.11+
- NumPy and Pandas
- Matplotlib
- yfinance
- pytest
